# Old Psensor GUI

This is the old version of PSensor GUI. It's no longer maintained.

Why not ???
- It requires lots of heavy dependencies and some of them are old and no longer available to install on some linux distributions
- It relies on the use of GTK+ for the gui which makes very difficult to work on it
- Configuration dosen't save when running as root
- Some of the UI components can be missing depending on the window manager



This will be removed soon
